# kniga2-posobie

Интерактивное пособие по второй книге «العربية بين يدي أولادنا» для детской Zoom-группы (8–13 лет).

- Сайт (GitHub Pages): `https://dzhos7465-dotcom.github.io/kniga2-posobie/`
- Тест урока ٥ для домашки: тот же адрес + `#l5-test`

## Устройство
- `src/template.html` — оформление и логика (места `/*DATA*/` и `/*ASSETS*/`).
- `lessons/urokN/` — материалы урока: `data.js` (тексты, ключи, рамки), `img/`, `audio/`, `book/` (PDF страниц урока).
- `build.py` — собирает `docs/index.html` (всё вшито в один файл).
- Решения по оформлению, правила и статус уроков — в памятке проекта Claude `claude/posobie-kniga-2.md`.
