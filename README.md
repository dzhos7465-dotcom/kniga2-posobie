# kniga2-posobie

Интерактивное пособие по второй книге «العربية بين يدي أولادنا» для детской Zoom-группы (8–13 лет).

- Сайт (GitHub Pages): `https://dzhos7465-dotcom.github.io/kniga2-posobie/`
- Тест для домашки: тот же адрес + `#l5-test`, `#l6-test` (номер урока)

## Устройство
- `src/template.html` — оформление и логика, без содержимого уроков (места `/*DATA*/` и `/*ASSETS*/`).
- `lessons/book.js` — карта книги (`BOOK`, `ready:true` у готовых уроков).
- `lessons/urokN/` — материалы урока: `data.js` (`LESSONS[N]={…}`: тексты, ключи, рамки, слушание, звуки, чтение, буквы, نَشَاط, подсказки), `img/`, `audio/`, `book/` (PDF страниц урока).
- `build.py` — собирает все уроки в `docs/index.html` (всё вшито в один файл; картинки и звук каждого урока в `ASSETS[N]`).
- Новый урок: папка `lessons/urokN/` с `data.js` по образцу урока ٦ + `ready:true` в `book.js`. Шаблон трогать не нужно.
- Решения по оформлению, правила и статус уроков — в памятке проекта Claude `claude/posobie-kniga-2.md`.

## Правило для всех чатов: GitHub — единственная общая точка
- Любая правка считается сделанной только после `git push`. Показал Джо скриншот или файл — в тот же момент отправь коммит в свою ветку.
- В конце каждого ответа с правками пиши Джо номер коммита и ветку.
- Перед началом работы: `git fetch` и смотри последние коммиты всех веток (`git log --oneline --all -10`). Не опирайся на то, что «было в прошлом чате».
- Ветки: `main` — сайт для детей, только после «да» Джо; `pravki-0311` — оформление (главный чат); `urokN` — урок N (чат урока, ветка от свежего main).
- Статус каждой ветки — в разделе «Ветки» памятки проекта `claude/posobie-kniga-2.md`, с номером последнего коммита.
