## Звук (папка `audio/`, 165 файлов)
Архив `الكتاب-الثاني-الوحدة-الثانية`. Вступление отрезано, паузы — цифровая тишина (проверено, громче −60 дБ нет ни одной).
- `d_0…d_9` — построчный проход диалога (76–147 с файла 1-01), без музыки. Кусок 71,7–73,9 с — хвост музыкального прохода, не взят. Реплики: من الأول؟ / الأول مشتاق، هو نحيف / ومن الثاني؟ / الثاني أحمد… صالح / من الخامس؟ / الخامس بهاء… التاسع أنا / ومن العاشر؟ / أنت العاشر. أنت الأخير / أنا مريض / أنت سمين. `d_full` — подряд с паузой 0,7 с.
- `a_awwal, a_thani, a_thalith, a_rabi, a_khamis, a_sadis, a_sabi, a_thamin, a_tasi, a_ashir, a_marid, a_akhir, a_nahif, a_samin` — порядок сверен с видео (звук видео совпадает с файлом).
- `x3_*`, `x4_*`, `x5_*` — номер + слово одним клипом.
- `s1_0…8` — имена: خَالِد، قَاسِم، سَالِم / شَاكِر، سَلْمَان، عُثْمَان / عَدْنَان، إِسْمَاعِيل، طَارِق.
- `s2_0…41` — башенки: правая, средняя, левая, сверху вниз; в паре сначала ـَ, потом ا (длительности это подтверждают: чётные короче нечётных).
- `s3_0…8` — аяты سورة الشمس 1–9.
- `s4_0…9` — 10 звуков «подними руку на фатху».
- `x7_0…13` — номер + фраза; №13 и №14 — по две фразы (разговор двоих).
- `h_0…27` — названия букв ألف … ياء по порядку книги.

- صِلْ кольцами стр. ١٢: السَّادِس ب، الثَّانِي ب، الثَّالِث أ، التَّاسِع أ، الْأَوَّل ب، الثَّامِن أ، الرَّابِع ب، الْعَاشِر ب، سَمِين ب، مَرِيض ب، السَّابِع أ، الْأَخِير أ، نَحِيف أ، الْخَامِس ب.

## Картинки (папка `img/`, до Upscayl)
- `w_*` — 14 кадров видео (670×700).
- `scene` — сцена забега **из скана книги**: в видео бегуны появляются по очереди, а сверху слева логотип закрывает трибуны. В книге видны все десять мальчиков и Фадль с эстафетной палочкой.
- `b_pairs` — бегуны стр. ١٤ (для рамок пар), `b_nashid` — страница нашида ٢٠.
- Архив для Upscayl: `kartinki_urok2.zip`.

## На заметку
- Нашид «الْوُضُوءُ» стр. ٢٠: в архиве издателя его записи нет. Нужен звук от Джо или ссылка.
- Стр. ١٩ упр. ٣ «лишнее слово»: هَذَا / هَذِهِ, أَنْتَ / أَنْتِ, مُعَلِّم / مُعَلِّمَة, حَالُكَ / حَالُكِ — различие по одной огласовке или букве. مُعَلِّمَة и حَالُكِ в рамках урока не звучат.
- **هُوَ** впервые в диалоге (الْأَوَّلُ مُشْتَاقٌ، هُوَ نَحِيفٌ).
