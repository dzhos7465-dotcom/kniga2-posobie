## Звук (папка `audio/`, 131 файл)
Архив `الكتاب-الثاني-الوحدة-الثالثة`. Вступление отрезано, паузы — цифровая тишина (проверено).
- `d_0…d_7` — построчный проход диалога (59,7–120 с файла 1-01), без музыки. Реплики: الأولى، الثانية، الثالثة / اسكتي / لن أسكت، الرابعة… السادسة / اسكتي / لن أسكت، السابعة… التاسعة / اسكتي / العاشرة أختي نذيرة / مبارك.
- `a_ula, a_thaniya, a_thalitha, a_rabia, a_khamisa, a_sadisa, a_sabia, a_thamina, a_tasia, a_ashira, a_yaskut, a_ukht, a_mubarak, a_lan` — порядок сверен с видео.
- `s1_0…8` — имена: إِبْرَاهِيم، سَلِيم، عَبْدُ الرَّحِيم / سَعِيد، فَرِيد، لَطِيفَة / جَمِيلَة، حَلِيمَة، سَمِيرَة.
- `s2_0…29` — башенки: правая, средняя, левая; в паре сначала ـِ, потом ي (чётные короче — подтверждается).
- `s3_0…7` — аяты سورة التين 1–8.
- `s4_0…10` — 11 звуков «подними руку на кясру».
- `x7_0…13` — номер + фраза.
- `r1_0…7` — карточки стр. ٢٨ по буквам أ…د: أُخْت، سَيَّارَة، حَقِيبَة، قَلَم، الْأُولَى، الثَّانِيَة، الْخَامِسَة، الْعَاشِرَة (порядок по буквам книги, на слух не сверен).
