# Урок ٧ أُسْرَةُ بَتُولَ (стр. ٦٣–٧٢) — заметки

Ветка `urok7`. Урок в общем приложении: `LESSONS[7]`, домашка `hw/l7-1.html`, `hw/l7-2.html`, `hw/l7.html`.

## Чем урок ٧ отличается от ٥ и ٦ (и что добавлено в шаблон)
Все добавления необязательные: у уроков ٥ и ٦ их нет, их вид на компьютере не изменился (сверено попиксельно).
- **Три говорящих** в диалоге (لَطِيفَة، بَتُول، صَفِيَّة). Цвет строки идёт через одну, поэтому صَفِيَّة зелёная. «Кто это сказал?» в тесте берёт говорящих только из `lines` части (`HW[].lines`) или `whoLines` урока — строка ٨ (صَفِيَّة) исключена.
- **Дерево + صِلْ в одной части** (стр. ٦٤): если есть и `TREE`, и `MATCH1`, в дереве появляется третья кнопка «Соедини · стр. ٦٤».
- **Звуки таблицами** (стр. ٦٨–٦٩): `STAB` — три таблицы «فِي الْأَوَّلِ / فِي الْوَسَطِ / فِي الْآخِرِ» (ص ز س, ق ك ج, ض ظ ذ ز د) и игра «Какой звук?» с точным ключом по таблице. Если `STAB` нет, работает старый раздел звуков.
- **Нашид** (стр. ٧٢): `nashid:{title,page,img,audio}` — кнопка в نَشَاط открывает страницу книги и запись издателя `n_0`. Нашид звучит с музыкой — это песня, правило «без музыки» относится к репликам и упражнениям.
- **«Читаем по очереди»** теперь принимает любое число строк (по 3 на страницу). В уроке ٧ их 9: упр. ١ и упр. ٢ стр. ٧٠.
- Телефон: таблицы звуков в одну колонку, «Читаем по очереди» в одну колонку.

## Звук
- `d_0…d_9` — второй, построчный проход L01E01 (77–168 с), паузы тишина, `d_full` собран из реплик.
- `a_*` — L01E02, порядок как в рамке и в видео.
- Таблицы звуков: L04E01 → `s1_0…53`, L04E02 → `s2_0…53`, L04E03 → `s3_0…64`. Порядок проверен по записи: строка за строкой справа налево (внутри строки похожие слова, на границах строк скачок). В L04E03 диктор объявляет разделы «في الأول / في الوسط / في الآخر» — эти три фразы вырезаны.
- Слушание: L02E03 → `x3`, L02E04 → `x4`, L02E05 → `x5`, L04E04 (стр. ٦٩) → `x9`.

## Ключи
- Упр. ٣ стр. ٦٥: 1ب 2ب 3أ 4أ 5أ 6ب (сравнение с эталонными словами, разрыв уверенный).
- Упр. ٤ стр. ٦٥: 1ج(جَدَّة) 2ب 3ت 4خ 5أ 6ث 7ح.
- Упр. ٥ стр. ٦٥: أَطْفَال1 صَدِيقَة2 زَوْجَة3 زَوْج4 مِنْ فَضْلِكِ5 جَدَّة6 مَعَ7.
- Упр. ٤ стр. ٦٩ (`x9`): звучат фразы, ключ не определён — проверяет учитель.
- Упр. ٢ стр. ٧٠: أ-ت، ب-ث، ت-أ، ث-ج، ج-ب (в `QA`, шаблоном пока не используется, ответы стоят в «Читаем по очереди»).

## Слова вне банка
- Рамка слов: جَدَّة، زَوْج، زَوْجَة، أَطْفَال، صَدِيقَة، مِنْ فَضْلِكَ/كِ، مَعَ.
- Диалог и рамки: وَرَحْمَةُ اللهِ وَبَرَكَاتُهُ، مَعَ السَّلَامَةِ، وَلَد (рамка пар ١).
- Текст стр. ٧١: عَمَّة (узнавание), слитное ـهَا (بَيْتُهَا، زَوْجُهَا، وَلَدُهَا), имя مُنِير. В книге «بَيْتُ عَمَّتِي صَفِيَّةُ», исправлено на صَفِيَّةَ.
- Слова таблиц звуков — тренировка звука, значения не разбираются.
- Пары: упражнения книги для девочек; мальчику приложение задаёт вопрос с ـكَ. Карточка «أَيْنَ زَوْجُكِ؟» — роль صَفِيَّة, одна для всех.

## Картинки
- `w_*` — кадры из видео (440×460, увеличены до 670×700), `scene` — сцена из видео без логотипа.
- `b_tree` и рамки дерева — из урока ٥ (то же дерево). `b_walida` (فَاطِمَة), `b_ukht` (هَالَة), `b_ibna` (خَوْلَة), `b_walad` (عِيسَى) — портреты из дерева без табличек с именами.
- `w_amm, w_khal, w_akh, w_jadd, w_sadiq, b_walid` из урока ٥, `w_hidha, b_haqiba, b_sayyara` из урока ٦.
- Из скана: `b_c1…c6` (пары стр. ٦٧), `b_x9_*` (стр. ٦٩), `b_r1…r4` (стр. ٧٠), `b_chtenie` (стр. ٧١), `b_nashid` (стр. ٧٢).
